Initial interpretation and design decisions (superseded layout)

  • The current request to refactor the ISS application takes precedence over the attached SpaceEdu planet-course implementation. That attachment supplies cinematic hierarchy, restrained cyan-family accents and serif emphasis. This remains the existing React/Vite/Three.js application, rather than a standalone HTML planet switcher.
  • The globe has a dedicated right-hand area; narrative and action share a left edge. Telemetry forms a separate six-column strip. On phones, the reading order becomes narrative, action, globe, telemetry.
  • Proposed palette: midnight #080e15, warm white #f1f3ef, mint #9ddbcc; these are new product choices authorized by the brief. Inter handles UI and telemetry, Instrument Serif retains editorial emphasis, JetBrains Mono handles small labels. Fonts fall back to system sans, Georgia, and monospace.

Layered layout contract

  • Rhythm: 8px base, 16/24/32/48/64 spacing; 4px used for compact segmented-control insets.
  • Frame: fluid desktop margins of 24–64px; 24px mobile safe area (20px below 380px). Desktop uses a 5:7 split and a shared full-width telemetry baseline. Long content may increase page height rather than clip.
  • Groups: 8–12px label/value gap, 24px narrative grouping, 32px between mobile content groups. Fine rules separate meaning without a card around every statistic.
  • Typography: headline 72–124px, narrative 16px, labels 11px. Hero action uses a deliberate fourth role at 13px for a compact, legible button. Short desktop viewports use an 80px headline and 14px narrative. Telemetry uses 11px metadata and 22–36px values; small-screen units stack below values.
  • Reduced motion removes transitions and rotational easing; live position updates continue because they carry information.

Rendering changes and tradeoffs

  • The marker and follow camera use the existing orbital propagator each animation frame. React telemetry still updates once per second; the live feed still polls every four seconds. Predicted movement between API samples is not a new measurement or precision orbital solution.
  • Orbit geometry is rebuilt on a new propagator rather than on every display-clock tick. Sunlight updates once per second using the existing approximate sub-solar calculation. A restrained atmosphere rim replaces the previous flat surface grading.
  • Hidden tabs suspend the render loop; resizing handles zero-size containers; geometries, materials, textures, event listeners and the renderer are disposed on unmount. WebGL creation failure shows a message while telemetry remains usable.
  • No dependencies added or upgraded. Existing pinned Three.js is retained. Earth imagery remains the existing external texture, and Google Fonts remains external; this is not an offline bundle.
  • Removed the unsourced fixed crew count from the live-looking telemetry strip. Corrected the displayed source to the actual feed provider. The pass-time dialog no longer renders focusable controls while closed.
